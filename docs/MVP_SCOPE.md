# MVP scope

The owner chose the full commercial platform (Option C) as the target. To deliver that safely, work still ships in vertical slices, each usable and tested. The first public beta (Phase 24) needs at least:

| Capability | Why it's in the beta | State |
| --- | --- | --- |
| Big Five quick + comprehensive | Core value and acquisition | ✅ |
| Archetypes and results report | Core value | ✅ |
| Accounts, history across devices, export, deletion | Trust, retention, legal | ⬜ Phase 5 |
| AI coach (grounded, limited free usage) | Main retention and subscription driver | ⬜ Phase 8 |
| Shareable personality card | Organic growth | ⬜ Phase 7 |
| Premium subscription + comprehensive report/PDF | Revenue | ⬜ Phases 15–16 |
| Mobile app (Expo) with the same flows | Platform reach | ⬜ |
| Growth plans (7-day) | Retention | ⬜ Phase 13 |

Deferred past beta: enterprise portal, multilingual content, relationship and leadership modules beyond basic versions, advanced analytics.
