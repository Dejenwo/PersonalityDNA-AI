# Scientific validation plan

No validation claims are made for PersonalityDNA today. The IPIP instruments have published evidence; the product's archetypes and any original modules have none. This plan defines what must happen before any claim is made.

## Governance

- Appoint an independent reviewer with a doctorate in personality psychology or psychometrics (owner decision; cost). Until then, user-facing text says "based on research instruments" and never "scientifically validated".
- All wording about traits, archetypes and limitations goes through that reviewer before launch.
- Changes to scoring or content create new versions and are logged in ASSESSMENT_METHODOLOGY.md.

## Studies (require informed research consent, separate from product consent)

| Property | Method | Target |
| --- | --- | --- |
| Internal consistency | Cronbach's alpha and McDonald's omega per trait on product data | Compare with published values; report honestly |
| Test–retest | Invite consenting users to retake after 2–4 weeks | Correlations per trait |
| Factor structure | CFA / ESEM on 50-item data | Five-factor fit indices |
| Quick vs comprehensive | Same users take both | Correlation per trait |
| Archetype stability | Retest agreement of primary archetype | Report agreement rate; if low, present archetypes even more cautiously |
| Measurement invariance | Multi-group CFA by language, gender, age group | Configural, metric, scalar before cross-group comparisons |
| Response biases | Acquiescence index (balanced keys), quality flag rates | Tune flag thresholds |
| Norms | Consenting sample with demographics | Only then add percentiles, versioned |

Minimum sample for factor analyses: several hundred per group (exact power analysis by the reviewer).

## Translations

Forward translation by two translators, reconciliation, back translation, cognitive interviews with native speakers, then invariance testing before a translated version is offered as equivalent.

## Original modules

Leadership, communication and similar original questionnaires are labelled "exploratory, not validated" until they pass the studies above.
