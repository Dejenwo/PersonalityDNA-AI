# Personality archetypes

Defined in `assessment-content/scoring-rules/archetypes.v1.json` (version 1.0.0). Original descriptive summaries, not validated types. Not derived from MBTI, 16Personalities or any proprietary system.

## Method

1. Centre each Big Five score: `d = (score − 50) / 50` (−1 to 1).
2. Each archetype has a prototype of +1 (higher), −1 (lower) or 0 (not relevant) for each trait.
3. Fit = Σ(prototype × d) / √(number of relevant traits).
4. Highest fit is primary, next is secondary; ties break by list order.
5. If the best fit is below 0.15, the profile is "balanced" and archetypes are shown as weak matches.
6. "Drivers" list the traits that raised the fit, so the explanation is always traceable to scores.

## Language rules

Archetypes describe tendencies ("tends to"), list strengths and growth ideas for each, and the results page states that most people show several. Names have not been checked for trademarks (KNOWN_ISSUES).
