## Coverage by area

| Unit testing | Backend lines are 97% covered. The lowest modules were the SMTP sender (71%) and the payment HTTP client (79%), and both now have tests with the network replaced. Web unit tests cover the logic in `src/lib` and `src/i18n`; components are covered through end-to-end tests. |
| --- | --- |
| Integration testing | API tests run against a real database (SQLite and PostgreSQL), including migrations and data migrations. Outbound email and payment calls are tested with fakes. Live providers (SMTP, Stripe, RevenueCat, Anthropic) have not been exercised because there are no accounts yet. |
| End-to-end testing | 16 flow specs on desktop and mobile: assessment, results, account, journal, goals, growth, coaching (stand-in), relationships, reports, sharing, pricing, careers, leadership, emotional awareness, organisations, languages, growth infrastructure and admin. |
| Accessibility testing | axe in every flow, plus a sweep of every screen in both colour schemes. Automated checks find only part of the WCAG problems; a manual screen-reader and keyboard pass is part of the beta checklist. |
| AI evaluation | The stand-in provider passes every safety suite. This shows the guards and routing work; it says nothing about a live model's behaviour. The live run (about 32 billed calls) waits for the owner's key, spending cap and approval. |
| Regression testing | Snapshots of the full result for each of the four instruments, the OpenAPI contract check, the released-content hash lock, and the whole-API security sweeps. |

## Findings

No defects were found in this phase. The accessibility sweep, integration tests and snapshots all passed on first run against the existing code. One problem was in the test environment, not the code: PostgreSQL had stopped in the sandbox, and the suite passed once it was restarted.

## Known gaps

- No manual screen-reader (VoiceOver, NVDA) or keyboard-only pass yet. It belongs in beta.
- No live-provider tests (email deliverability, Stripe test mode, RevenueCat sandbox, Anthropic). They need accounts.
- No load or performance tests yet; that is Phase 23.
- No mobile app tests, because there is no mobile app yet.
- No web component coverage numbers (no coverage tool in vitest). End-to-end tests cover the components.
