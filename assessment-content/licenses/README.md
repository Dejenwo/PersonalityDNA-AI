# Assessment licences

Every instrument in `../instruments` must have a licence record here before it can be loaded. The backend refuses to load an instrument whose `license.file` does not exist.

| --- | --- |
| [IPIP.md](IPIP.md) | ipip-bfm-50, mini-ipip-20 |
| [ONET.md](ONET.md) | onet-ipsf-60 (draft, CC BY-ND 4.0) |
| [ORIGINAL_CONTENT.md](ORIGINAL_CONTENT.md) | Archetypes and trait interpretation text (original, proprietary) |
